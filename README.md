# reflex-launcher-releases

Releases of the Open Reflex Launcher for Windows: the program that installs and updates the Open Reflex clients, makes their content from your own installed MX vs ATV Reflex, and starts them.

Get the newest from the [Releases](https://github.com/ItZFerret/reflex-launcher-releases/releases/latest) page: one executable, no installer. A launcher that is running tells you when a newer one is out.
